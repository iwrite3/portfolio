02 / Projects

Featured projects

Microservices · Cloud

FitTrack: AI-Powered Fitness Platform

A Spring Boot microservices fitness app with a React frontend. It logs calories burned per workout, generates AI insights, and tracks calorie burn across day, week, and 30-day windows.

GitHub Live Demo
  • Architecture: Four services (API gateway, user, activity, AI) on Google Cloud Run, with PostgreSQL and MongoDB for storage and RabbitMQ for background processing.
  • Security: Keycloak (OAuth2 with PKCE) and JWT validation enforced at the Spring Cloud Gateway, so downstream services stay stateless.
  • Async AI pipeline: The AI service estimates calories through OpenRouter and generates personalised recommendations asynchronously, so the user-facing request does not block on the LLM.
  • Delivery: Containerised with Jib and built through Cloud Build. Moved service config to environment variables and fixed real deployment issues from logs: database auth, a Spring Boot 4 config rename, and Keycloak cold starts.

Backend · LLM Integration

Know My Meal: Nutrition Tracker

A stateless RESTful Spring Boot backend that analyses nutrition in real time through the DeepSeek API, with a lightweight HTML and CSS front-end.

GitHub Live Demo
  • Stateless API design: Each request carries everything the server needs, so the service scales horizontally without session affinity.
  • Quota protection: Custom rate-limiting middleware (RateLimitInterceptor, RateLimiterService) blocks API abuse and protects the LLM quota from being exhausted.
  • Verification: Endpoints verified with Postman across the request and error paths.

Machine Learning · Web App

Bank Customer Churn Predictor & Retention Insights

An end-to-end churn pipeline on 10,000 bank customer records: EDA, feature engineering, an XGBoost classifier, and a Streamlit app that drafts retention strategies for high-risk customers.

GitHub Live Demo
  • EDA: Raw salary had near-zero correlation with churn, so I looked at relationships instead. Age separated churners from retained customers, and German customers churned at roughly twice the rate of French or Spanish customers.
  • Feature engineering: Built a BalanceSalaryRatio feature to capture how much of a customer's income sits idle in deposits, a signal for rate-sensitive savers.
  • Model: XGBoost classifier (max_depth=5, learning_rate=0.1, 100 estimators) on an 80/20 split, reaching 86% accuracy. Accuracy alone is misleading on this 80/20 class split, so I prioritised recall and F1 in evaluation.
  • Deployment: Model serialised with joblib. The Streamlit app deploys from GitHub on Streamlit Community Cloud, and the Groq LLM API drafts retention strategies for high-risk customers.
